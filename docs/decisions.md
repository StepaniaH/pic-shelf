## B. 决策与待决事项

### B0 · 长期规划（2026-10-11 定）
- 阶段一（当前）：本机自用（127.0.0.1）；
- 阶段二：**开源**；
- 阶段三：**Docker 部署 + 安装包**，面向外部使用；
- 远程访问：tailnet 内直连 `Tailscale IP:端口` 即可，**Caddy 子域非必需**（增量价值：HTTPS/安全上下文、域名好记、统一入口）。

### D1 · 全库静态加密（结论：现阶段不做；2026-10-11）

**已保护**：登录口令（scrypt 哈希，不可逆）；会话令牌（HMAC 签名，密钥文件 0600）；加密备份导出（可选口令）。
**未保护（明文躺在磁盘上）**：图片原文件、缩略图/预览图、数据库内容（标签/评分/评论）。

**结论（按推荐执行）**：**现阶段不做全库静态加密**。理由：
1. 当前威胁模型 = 自用服务器、单人使用、无不受信账号——物理接触/共用场景暂不存在；
2. 已做的「备份加密 + 口令/令牌防护」覆盖了最现实的泄露路径（备份文件流转）；
3. 判定标准一句话：**"库里有没有内容，是即使机器被物理接触也不愿被看到的？"**——若有，立即翻转为下面 (a)；若没有，现在不做就是合理答案，且**补做成本为零**（(a) 在部署层，不碰代码）。

**补做路径（触发条件：库内容敏感性变化 / 部署到共享环境 / 开源后用户需要）**：
- (a) **挂载层加密（gocryptfs / LUKS）**——给整个目录加「保险柜锁」：磁盘上全是密文，解锁后是普通文件夹，Pic Shelf 零改动。代价：启动需解锁，**口令丢失 = 数据无法恢复**；Docker 作为宿主层挂载后 bind 进容器。**标准答案，推荐**。
- (b) 应用层逐文件加密——**明确不做**（复杂度/性能/故障面不划算）。
- (c) 仅数据库加密（SQLCipher）——防护价值最低，不单独采用。
- 开源阶段动作：在 Docker 部署文档提供 (a) 的可选指引（文档级，非代码级）。

### D10 · 库模型：托管库（2026-10-11；CLI + Web 向导已落地）
- 决策：**托管模式为终态**，索引模式保留为兼容选项；提供「不改原库」的能力（hardlink / copy）。
- 每库一个 `mode`：
  - `index`——壁纸类「已经分好组、不想动」的场景（保留）；
  - `import·hardlink`——**默认**：原文件不动、库内规范化命名、同盘零额外空间（跨盘自动降级 copy）；
  - `import·copy`——原库留档（适合原库在 NAS）；
  - `import·move`——经典「整理」，执行前强制确认。
- 实施进展：
  - [x] `picshelf/importer.py`：预演计划 + hardlink/copy/move + sha256 去重 + 同名自动改名 + 越界防护 + 跨盘降级；
  - [x] CLI `picshelf import <源目录> <库名>`（默认预演；`--apply` 执行；`--yes` 跳过确认；完成后自动扫描）+ `library add --mkdir`；
  - [x] Web 管理页「导入」向导：`/api/v1/import/plan`（预演）+ `/api/v1/import/execute`（confirm 必填；move 由前端二次确认），需对目标库有 manage 权限；浏览器 E2E 实测通过；
  - [x] 测试 11 项（含 EXDEV 降级、冲突改名、重导入全跳过、move 需确认、API 流程与权限拒绝）；
  - [ ] 命名模板增强（基于 tag/艺术家的目录模板，依赖元数据规范化的后续迭代）。

### D12 · 双语文案（zh/en i18n，2026-10-11）
- 决策：**以中文原文为 msgid 的目录式映射**（Python：`picshelf/i18n.py`；Web：`web/js/i18n.js`），缺译回退中文；零运行时依赖、零构建。
- 语言解析：显式 `--lang` > `PICSHELF_LANG` > `LC_ALL/LANG`（zh* → zh）> 默认 `en`；API 按请求 `Accept-Language`；Web 顶栏「中/EN」切换（localStorage 持久化，`Accept-Language` 随请求发送）。
- 覆盖：CLI（含 `--help` 渲染时本地化）、TUI、Web（`index.html` 静态骨架走 `data-i18n` 惰性渲染 + 动态模板 `t()`）、API 报错文案。
- 转换工具：AST 级 Python 转换器 + 词法级 JS 转换器一次性完成机械包裹（产物已内化，不随仓库分发）；转换后逐条校验占位符集合一致（0 不一致）。
- 维护约定：新增文案写中文原文 + 在两侧目录补 EN；测试锁定 zh（conftest 设 `PICSHELF_LANG=zh`）。
